# Pesquisa de Atendimento

Programa desenvolvido em Python para realizar uma pesquisa de opinião
com clientes da empresa de marketing

## Opções de atendimento

1 - EXCELENTE  
2 - BOM  
3 - RUIM

O programa realiza a pesquisa com 50 entrevistados e apresenta ao final
a quantidade de respostas EXCELENTE e RUIM.

## Estruturas utilizadas

- Estrutura de repetição `for`
- Estrutura de decisão `if` e `elif`
